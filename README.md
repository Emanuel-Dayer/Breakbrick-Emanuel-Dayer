## 🎮 Descripción
Este proyecto busca crear una replica de este iconico juego para practicar habilidades de programación, comenzando con una version reducida del mismo, y encaminarse a la programación orientada a objetos

## ⌨️ Controles
● Movimiento de la pala: W, A / Flechas direccionales

● Lanzar Bola: Barra espaciadora
